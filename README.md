
# 🗳️ Sistema de Votação do Grêmio Estudantil

Sistema web desenvolvido para apoiar o processo de votação do Grêmio Estudantil da **Escola Estadual Laudelino Professor**, localizada em Praia Grande – SP.

Este projeto foi desenvolvido com o objetivo de digitalizar a votação escolar, proporcionando uma experiência simples para os estudantes e facilitando a organização do processo eleitoral.

## 📌 Sobre o projeto

O sistema permite que os estudantes acessem a votação, conheçam as chapas participantes e registrem seu voto por meio de uma interface web.

O projeto também contempla mecanismos para verificar se um estudante já votou, ajudando a evitar votos duplicados.

## ✨ Funcionalidades

- 🪪 Identificação do estudante por RA.
- 🗳️ Apresentação das chapas participantes.
- ✅ Confirmação e registro do voto.
- 🔒 Verificação para impedir que o mesmo RA vote novamente.
- 📊 Consulta dos resultados da votação.
- 💻 Interface web para utilização no ambiente escolar.

As tecnologias e ferramentas devem ser conferidas nos arquivos do repositório antes de publicar esta seção.
